# Editorial style decisions

This file records editorial conventions, not claims about objective Latin
meaning. Add dated decisions here only after human review.

## Current conventions

- No project-level rendering choices have yet been approved.
- Scripture wording retrieved from CPDV is comparison help, not drafting input
  and not lexical authority.
- Bracketed additions and uncertainty markers must remain visibly editorial.

## Decision template

### YYYY-MM-DD — Short title

- **Scope:** names, Scripture, capitalization, ecclesiastical term, brackets,
  or recurring convention
- **Decision:** the approved editorial rendering
- **Reason:** editorial rationale (kept separate from lexical evidence)
- **Examples/source units:** stable source-unit IDs
- **Supersedes:** earlier decision ID, if any
